### About Me

I'm a Statistics student interested in using statistical methods and machine learning to understand real-world data and build useful analytical systems.

Most of my projects sit somewhere between analysis and software: collecting and cleaning data, designing features, evaluating models, interpreting results, and turning the output into a dashboard or tool that can actually be used.

* 🔭 Building **SiHEWA**, a SARIMA–XGBoost commodity-price forecasting system for Cilegon, Indonesia
* 🌱 Learning more about **time-series forecasting, model monitoring, and reproducible ML workflows**
* 📊 Interested in **forecasting, fraud detection, anomaly detection, customer analytics, and data quality**
* 🎯 Open to **data analyst / data science internships**, research collaborations, and practical data projects
* 📚 Keeping notes and learning logs at **[study.salajalaludin.site](https://study.salajalaludin.site/)**

#### 🌾 SiHEWA

Commodity-price monitoring and forecasting system for Cilegon, Indonesia.

* Integrates scraped market prices, ERA5 climate data, and BMKG forecasts
* Uses **SARIMA** for the temporal component and **XGBoost** for residual modeling
* Produces three-day price forecasts and distribution-risk warnings
* Uses **SHAP** to inspect feature contributions
* Served through an interactive **R Shiny** application

`R` `Shiny` `Python` `SARIMA` `XGBoost` `SHAP`

#### 💳 Fraud Detection

Transaction risk-scoring system for prioritizing potentially fraudulent transactions.

* Trained an **Extra Trees classifier** on highly imbalanced transaction data
* Tuned the classification threshold around the precision–recall trade-off
* Reached **94.83% precision**, **77.46% recall**, and **85.27% F1**
* Added permutation importance and model-drift monitoring
* Includes a Streamlit investigation dashboard, tests, and CI

`Python` `scikit-learn` `Streamlit` `pytest` `GitHub Actions`
